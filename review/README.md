## 推荐复习顺序

1. **建立框架：** 阅读[期末复习总笔记](密码分析学期末复习总笔记.md)，串起各类攻击的条件、步骤与复杂度。
2. **补齐薄弱点：** 按[专题目录](../notes/README.md)回看不熟悉的推导和课件图，重点手算差分、线性传播与密钥恢复。
3. **用实验检验理解：** 阅读[实验复习指南](实验复习/README.md)，核对 DDT/LAT、路径概率、候选计数和建模约束。
4. **独立完成试卷：** 使用[模拟试卷](模拟试卷/密码分析学期末模拟试卷.md)，按 120 分钟完成 100 分试题。
5. **对照评分复盘：** 阅读[参考答案与评分要点](模拟试卷/密码分析学期末模拟试卷参考答案与评分要点.md)，把错误定位到公式、传播、计数或复杂度单位。

时间安排见[11 月 18 日考试复习计划](11月18日密码分析学复习计划.md)。
