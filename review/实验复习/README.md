## 贯穿实验的三组区别

**差分统计与线性统计。** DDT 记录固定输入差分产生某个输出差分的次数；本实验 LAT 记录线性等式成立次数减去输入总数的一半。DDT 是非负计数，LAT 可以为负。对于 4 位 S 盒：

$$
p_{\alpha\to\beta}=\frac{\operatorname{DDT}[\alpha,\beta]}{16},\qquad
\varepsilon_{a,b}=\frac{\operatorname{LAT}[a,b]}{16},\qquad
c_{a,b}=2\varepsilon_{a,b}=\frac{\operatorname{LAT}[a,b]}8.
$$

**一条路径与同一端点下的所有路径。** 单条差分特征按模型把逐层概率相乘，端点差分要汇总各条相容特征；线性路径保留相关系数的符号，汇总时可能相消。完整差分或线性包络由全部相容路径共同决定。

**区分与密钥恢复。** 区分利用统计量偏离随机基线的现象；密钥恢复则猜测一部分密钥并局部解密，再用这一统计现象给候选排序，逐步恢复密钥。

## 考前手算清单

1. 给定一个 S 盒和输入差分，遍历全部输入，写出一行 DDT，并检查行和。
2. 给定输入、输出掩码，数线性等式成立的次数，换算 LAT、偏差、相关系数。
3. 沿一条多轮路径写出每轮状态，计算概率或带符号相关系数。
4. 写出最后一轮的逆运算，明确猜哪些密钥位、检查什么条件、怎样排名。
5. 给定一个非法二进制点，写出恰好排除它的线性不等式。

这些步骤分别对应[差分攻击](../../notes/03-差分分析/差分攻击.md)、[线性分析](../../notes/04-线性分析/线性分析.md)和[自动化区分器搜索](../../notes/09-自动化与拓展/自动化区分器搜索.md)的核心内容。
