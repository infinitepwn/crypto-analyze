\subsubsection{逻辑化简法}
\label{subsubsec:lab4-task1-logic-minimization}

\paragraph{非法点函数的构造与化简}

逐点排除法为每个非法点分别建立约束。逻辑化简法则先构造八输入布尔函数，使其在非法点上取值为1、在合法点上取值为0，再利用Espresso将函数化简为若干乘积项。每个乘积项对应一个逻辑立方体，其中部分坐标固定为0或1，其余坐标为通配位；一个立方体可以覆盖多个非法点。

本实验在\texttt{logic\_minimization.py}中通过PyEDA的\texttt{espresso\_exprs}接口调用Espresso。\footnote{PyEDA的Espresso接口及两层逻辑化简说明：\url{https://pyeda.readthedocs.io/en/latest/2llm.html}。}程序按公共位序建立八个布尔变量，为DDT或LAT中的每个零值位置生成一个最小项，并将所有最小项取逻辑或：
\par\noindent\begin{minipage}{\linewidth}
\begin{lstlisting}
variables = exprvars("x", 8)
minterms = []
for a in range(SIZE):
    for b in range(SIZE):
        if table[a][b] == 0:
            point = bits(a, b)
            minterms.append(And(*(
                variable if value else ~variable
                for variable, value in zip(variables, point)
            )))

forbidden_function = Or(*minterms).to_dnf()
minimized, = espresso_exprs(forbidden_function)
\end{lstlisting}
\end{minipage}\par

化简后的析取范式仍表示同一个非法点函数。程序从\texttt{minimized.to\_dnf().cover}读取各乘积项：正文字表示该位固定为1，负文字表示固定为0，未出现的变量表示通配位。读取文字时根据变量标识还原坐标下标，保证其顺序仍为$(a_3,a_2,a_1,a_0,b_3,b_2,b_1,b_0)$。

\paragraph{立方体到线性约束的转换}

对每个非法立方体$c$，排除它的条件是当前点至少有一个固定坐标与$c$不同。固定为0的坐标贡献$x_j$，固定为1的坐标贡献$1-x_j$，通配位不参与求和。程序据此为每个立方体添加一条线性不等式：
\begin{lstlisting}
x = model.addVars(8, vtype=gp.GRB.BINARY)
for cube in cubes:
    model.addConstr(gp.quicksum(
        x[j] if value == 0 else 1 - x[j]
        for j, value in enumerate(cube) if value is not None
    ) >= 1)
\end{lstlisting}

因此，一条约束可以同时排除该立方体覆盖的多个非法点。Espresso负责化简非法点函数并给出立方体覆盖；随后，程序将这些立方体转换成线性约束，由求解器枚举可行点。

\paragraph{实验结果与分析}

图~\ref{fig:lab4-task1-logic-minimization}展示了立方体约束模型的枚举结果。本次化简为DDT非法点集生成36个立方体，为LAT非法点集生成38个立方体，因此模型分别包含36条和38条不等式。与逐点排除法的184条和134条不等式相比，逻辑化简在变量数仍为8的条件下减少了约束条数。
