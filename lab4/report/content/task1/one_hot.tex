\subsubsection{one-hot法}
\label{subsubsec:lab4-task1-one-hot}

\paragraph{实验过程与关键代码}

one-hot法从DDT或LAT中提取所有非零位置，组成传播点集$V$。对每个点设置一个二进制选择变量$\lambda_{(a,b)}$，并要求所有选择变量之和为1，从而使每个模型解恰好选中一个传播点。

程序通过\texttt{bits(a,b)}计算每个传播点的八位编码，再建立八个原始变量和相应的选择变量：
\begin{lstlisting}
V = [(a, b) for a in range(SIZE) for b in range(SIZE) if table[a][b] != 0]
x = model.addVars(8, vtype=gp.GRB.BINARY)
lam = model.addVars(V, vtype=gp.GRB.BINARY)
model.addConstr(lam.sum() == 1)
\end{lstlisting}

选择变量确定所选传播点后，还需将该点的坐标恢复到原始变量$x$。对于第$j$位，只累加在该位取值为1的点所对应的选择变量：
\begin{lstlisting}
for j in range(8):
    model.addConstr(x[j] == gp.quicksum(
        lam[p] for p in V if bits(*p)[j] == 1))
\end{lstlisting}

因此，每个模型包含1条选点等式和8条坐标恢复等式，共9条显式约束。由于每个传播点只对应一个输入输出对，选择变量与八位坐标之间是一一对应关系。

\paragraph{实验结果与分析}

图~\ref{fig:lab4-task1-one-hot}给出了DDT和LAT模型的全解枚举结果。DDT模型包含72个选择变量和8个原始变量，共80个二进制变量；LAT模型包含122个选择变量和8个原始变量，共130个二进制变量。两个模型均包含9条等式，求解分别得到72个和122个解，所列输入输出对与DDT、LAT的非零位置逐项一致。
