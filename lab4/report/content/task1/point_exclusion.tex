\subsubsection{逐点排除法}
\label{subsubsec:lab4-task1-point-exclusion}

\paragraph{实验过程与关键代码}

逐点排除法先提取表中所有取值为0的位置，组成非法点列表\texttt{forbidden}。模型只使用八个原始二进制变量，并为每个非法点添加一条排除不等式。由于LAT的正值与负值均表示可达传播，非法点统一通过表项等于0来提取：
\begin{lstlisting}
forbidden = [(a, b) for a in range(SIZE) for b in range(SIZE)
             if table[a][b] == 0]
x = model.addVars(8, vtype=gp.GRB.BINARY)

for point in forbidden:
    q = bits(*point)
    model.addConstr(gp.quicksum(
        x[j] if q[j] == 0 else 1 - x[j]
        for j in range(8)
    ) >= 1)
\end{lstlisting}

对非法点$q$，当$q_j=0$时，$x_j$表示当前点在第$j$位与$q$不同；当$q_j=1$时，$1-x_j$表示该位与$q$不同。将八个坐标对应的差异项相加并要求总和至少为1，即可排除$q$。因此，每条不等式只排除一个指定的非法点。

\paragraph{实验结果与分析}

图~\ref{fig:lab4-task1-point-exclusion}给出了DDT和LAT模型的枚举结果。输入、输出各有16种取值，共有$16\times16=256$个候选点。DDT有72个合法点，因而需要排除184个非法点，对应184条不等式；LAT有122个合法点，对应134条排除不等式。两个模型均使用8个二进制变量，与程序输出一致。
