\subsubsection{凸包法}
\label{subsubsec:lab4-task1-convex-hull}

\paragraph{利用SageMath构造完整凸包}

凸包法包括凸包构造和约束求解两个阶段。构造脚本\texttt{build\_hull.py}从DDT或LAT的非零位置提取传播点，在八维空间中构造凸包并生成H表示；求解脚本\texttt{convex\_hull.py}读取这些约束，建立二进制模型并枚举可行点。

构造阶段将每个合法输入输出对按公共位序编码为八位向量，并在有理数域$\mathbb Q$上进行精确计算。程序分别提取凸包的不等式和等式：
\begin{lstlisting}
points = [bits(a, b) for a in range(SIZE) for b in range(SIZE)
          if table[a][b] != 0]
hull = Polyhedron(vertices=points, base_ring=QQ)

hrep = {
    "inequalities": sorted(integer_row(row)
                           for row in hull.inequalities_list()),
    "equations": sorted(integer_row(row)
                        for row in hull.equations_list()),
}
\end{lstlisting}

SageMath输出的每行系数按$[c_0,c_1,\ldots,c_8]$排列，其中$c_0$为常数项，对应的不等式为$c_0+\sum_{j=0}^{7}c_{j+1}x_j\ge0$；等式采用相同的系数顺序。\footnote{SageMath多面体构造与H表示说明：\url{https://doc.sagemath.org/html/en/reference/discrete_geometry/sage/geometry/polyhedron/constructor.html}。}为将系数保存为整数，\texttt{integer\_row()}先乘以分母的最小公倍数，再除以整数系数的最大公因数。缩放因子为正数，因此不等式方向保持不变。

完整H表示保存在\texttt{hull\_constraints.json}中。JSON文件以\texttt{DDT}和\texttt{LAT}为顶层键，每组包含\texttt{inequalities}和\texttt{equations}两个系数数组。文件位于Windows工作目录，WSL通过\texttt{/mnt/d/}路径访问并生成数据，Windows端随后读取同一文件。

\paragraph{贪心筛选与模型求解}

完整H表示准确描述凸包，但本任务关注其二进制可行点，因此在保留全部等式的前提下，进一步筛选能够排除非法二进制点的不等式。程序先将不满足等式的非法点移出待覆盖集合\texttt{remaining}，再由\texttt{pool}记录每条候选不等式所能排除的点。每轮选择覆盖当前最多剩余非法点的不等式，并从\texttt{remaining}中移除已排除点，直至待覆盖集合为空。核心循环如下：
\par\noindent\begin{minipage}{\linewidth}
\begin{lstlisting}
while remaining:
    row = max(pool, key=lambda item: len(pool[item] & remaining),
              default=None)
    if row is None or not (pool[row] & remaining):
        raise RuntimeError("Incomplete illegal-point coverage")
    chosen.append(row)
    remaining.difference_update(pool.pop(row))
\end{lstlisting}
\end{minipage}\par

函数\texttt{linear\_form(row,point)}计算不等式在指定点上的取值；若结果小于0，该点违反此不等式并被排除。候选行按系数顺序排列，使并列时的选择固定。每条保留约束均来自完整H表示，因而合法点仍满足所有保留约束；循环结束时全部非法点也均已排除。

最终模型使用八个二进制变量，将全部等式以$h(x)=0$、筛选后的不等式以$h(x)\ge0$加入模型，并按照统一的解池设置枚举全部可行点。

\paragraph{实验结果与分析}

图~\ref{fig:lab4-task1-hull-build}展示了SageMath构造完整凸包并保存H表示的输出。DDT凸包包含145条不等式，LAT凸包包含134条不等式，两者的等式数均为0，与两组传播点集的仿射维数均为8相符。对完整H表示进行二进制点核对，分别得到72个和122个可行点，与原始表中的非零位置一致。
