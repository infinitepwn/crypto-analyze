\subsection{任务一：DDT与LAT的建模及求解}
\label{subsec:lab4-task1}

% 本任务针对CipherFour的4比特 S 盒，分别采用one-hot法、逐点排除法、逻辑化简法和凸包法建立二进制线性约束模型，并枚举每种模型的全部可行解。实验首先通过遍历计算 S 盒的DDT与LAT，再将四种模型得到的解投影为输入、输出对，并与两张表中的非零位置逐点核对。DDT中的$(a,b)$表示输入差分和输出差分；LAT中的$(a,b)$表示输入掩码和输出掩码。% \footnote{本任务的代码实现与报告整理使用了AI工具辅助；实验数据来自实际运行结果，并由作者依据DDT、LAT进行了核对。}

\paragraph{DDT与LAT的直接计算}

四种建模方法共用\texttt{ddt\_lat.py}中的表格计算函数。计算DDT时，程序遍历每个输入差分$a$及每个输入$x$，求出$S(x)\oplus S(x\oplus a)$，并在对应的输出差分列累计出现次数：
\begin{lstlisting}
for a in range(SIZE):
    for x in range(SIZE):
        b = SBOX[x] ^ SBOX[x ^ a]
        table[a][b] += 1
\end{lstlisting}

计算LAT时，程序遍历输入、输出掩码$a,b$，统计满足$a\cdot x=b\cdot S(x)$的输入数，再减去$2^{4-1}=8$。按位与结果的汉明重量奇偶性用于计算模2内积，核心代码如下：
\begin{lstlisting}
equal_count = 0
for x in range(SIZE):
    input_parity = (a & x).bit_count() & 1
    output_parity = (b & SBOX[x]).bit_count() & 1
    if input_parity == output_parity:
        equal_count += 1
table[a][b] = equal_count - SIZE // 2
\end{lstlisting}

图~\ref{fig:lab4-task1-ddt-lat}给出了直接遍历计算得到的DDT和LAT。表格的行、列分别对应输入和输出，索引均以十六进制表示。DDT有72个非零表项，LAT有122个非零表项；因此，差分模型和线性模型分别应保留72个与122个传播点。LAT的负值同样表示非零偏差，构造合法点集时应保留所有非零表项；两张表均保留$(0,0)$。

\paragraph{统一编码与全解枚举}

为使四种方法的求解结果可以直接比较，每个输入输出对均按大端序编码为
\[
x=(a_3,a_2,a_1,a_0,b_3,b_2,b_1,b_0)\in\{0,1\}^8.
\]
其中输入和输出的高位均排列在前。各模型使用相同的位序，并将目标函数设为常数0，以枚举所有满足约束的二进制解。解池的关键设置如下：
\begin{lstlisting}
model.setObjective(0, gp.GRB.MINIMIZE)
model.Params.PoolSearchMode = 2
capacity = 2**8 + 1
model.Params.PoolSolutions = capacity
model.Params.MIPGap = 0
model.Params.MIPGapAbs = 0
model.optimize()
\end{lstlisting}

八位二进制向量共有$2^8=256$种赋值，因而将解池容量设为257，确保其严格大于完整赋值数。程序只有在求解状态为最优且解池未满时才确认枚举完成；随后逐个读取解，按照公共位序还原输入、输出，并以十六进制排序。每个解表示DDT或LAT中的一个非零位置，具体表项值仍由图~\ref{fig:lab4-task1-ddt-lat}给出。
