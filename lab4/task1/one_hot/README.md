# one-hot方法

公共遍历计算已移到上一级的 `ddt_lat.py`；本目录只负责one-hot建模、Gurobi枚举和最终结果打印。

首次在 `task1` 目录同步环境：

```powershell
uv sync
```

然后仍在 `task1` 目录运行：

```powershell
uv run python one_hot/one_hot.py
```

程序依次处理DDT、LAT，只打印每个模型的变量数、等式数、解数和全部输入输出对。输入输出以十六进制表示，并按输入、输出排序，供人工查看和比较。

不导出表格、约束、模型、日志或结果文件，不创建结果目录，也不进行自动解集比较。仍保留枚举完成状态检查，防止把未完成搜索的部分解当作全部解。

如需单独查看原始DDT、LAT，在本目录执行：

```powershell
python ../ddt_lat.py
```

后续其他方法可导入公共模块的 `compute_ddt()`、`compute_lat()` 和 `bits(a, b)`。表格按 `table[输入][输出]` 存储，位序为 `(a3,a2,a1,a0,b3,b2,b1,b0)`。LAT采用计数减8的定义，负数表项同样属于合法位置。

两个表格函数使用内存缓存，在同一Python进程中各只计算一次；共享的表格应只读使用。单独启动另一个脚本会创建新进程并重新计算，不会读取或写入持久化缓存。后续多种方法在同一个主程序中调用时即可复用已有表格。

环境由上一级的 `pyproject.toml` 和 `uv.lock` 管理，唯一第三方依赖是 `gurobipy`。代码保留Gurobi 12/13的解池属性读取方式。运行与人工比较由实验者完成。
