\section{任务二}
给定如下明密文数据流，任务1中的三个转子和反射器的定义不变，但转子顺序不固定，请尝试恢复密钥K1和K2。（假设加密过程中，中速和慢速转子不转动）

明文WETTERVORHERSAGEHEUTE

密文EWGZDSATLWNEDBBCJUNGW

\subsection{思路分析}
\subsubsection{分割密钥空间}
实验给的明文和密文长度一样，且没有出现明文字母和密文字母相同的情况，因此可以认为这就是对应的明密文，即Crib，

由于加密的时候密钥K1和K2是合并起来的，穷举数量太大，因此需要分割密钥空间，我们可以类比2-DES的攻击，通过一些相同的中间量来脱去外层加密,把\(K_1\)和\(K_2\)分开

前面探讨过，\(|K_1| >> |K_2|\),所以我们寄希望于消除掉\(K_1\),先回复\(K_2\)

\subsubsection{寻找中间状态}
我们注意到这样的一种特殊的Crib，即内部能形成环路的Crib，因为接线板就是一个由连接线决定的单表代换，这个过程和K2没有关系，
enigma机的明文输入会经过一次接线板，而输出密文前也会经过一次接线板，这之间有一个中间状态。

我们就可以利用这个中间状态单独回复\(K_2\)，然后再去恢复\(K_1\)，实现对于密钥空间的分割，降低密钥恢复的复杂度。

以课程上的一个crib为例，
\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{figures/crib.png}
    \caption{Crib}
    \label{fig:Crib}
\end{figure}
明文里的W,经过接线板，\(K_1\)我们可以理解成一个可逆的单表带换，即\(K_1(W)=L_0\)，

然后密文的E，\(K_1(E)=L_1\)，此时我们发现明文的下一个也是E，它得到的中间状态也应该是\(L_1\),那这样我们就能消解掉接线板的影响

(值得注意的是，这里的Crib是一种交替的环路，就是从明文-密文-明文-密文...这样明密文交替进行的，这实际上会影响后续的数据结构，参考程序中并不是这样的，不过这又是后话了)
\subsubsection{建立关于\(K_2\)的方程}
我们利用这个中间状态来建立K2的方程：

它有一个\textbf{不随机现象}，\(L_0\)进\(L_0\)出，
而\(L_1\)本身就是\(L_0\)经过扰频器和反射器得到的，也就是说，知道\(L_0\)和\(K_2\),就能计算\(L_1,L_2\)
\[
L_{i-1} \xrightarrow{K_2} L_i
\]
我们简单把这个步骤记作\({Enc}_{K_2}\)

因此这中间的路径也被消解了，我们只需要关注首尾的\(L_0\),正确的K2应该能让\(L_0\)进\(L_0\)出

也就是
\[
Enc_{K_2}^{n}(L_0) = L_0
\]

这里的\(n\)就是中间路径的长度

只需要遍历\(|K_2|\times|L_0|\)次，其中\(|L_0|=26\),这远远小于\(|K_1|\times|K_2|\)的穷举

当然这个也会有错误，但是我们多找几个环路，然后取交集，就能得到比较少的候选了
\subsubsection{根据环路恢复\(K_1\)以及\(K_2\)}
我们前面找到的可能的\(K_2\)的候选集，记为\(\{(L_0^{1i},K_2^1),(L_0^{2i},K_2^2),..., (L_0^{ni},K_2^n)\}\)
因为一个\(K_2\)可能对应多个\(L_0\),所以\(L_0^{1i},K_2^1\)可能有多个\(i\),即多个\(L_0\)对应同一个\(K_2\)

我们可以利用这些候选的\(K_2\)来恢复\(K_1\)，同时进一步筛选\(K_2\)

因为我们已知环路，比如W-E-E-T-T-W

那么就有\(K_1(W)=L_0\)，\(K_1(E)=L_1\)，\(K_1(T)=L_2\)，以此类推

同时还有\(K_1(L_0)=W\)，\(K_1(L_1)=E\)，\(K_1(L_2)=T\)

\(K_1\)本质就是一个长度为26的列表，每个环路，都能推出\(K_1\)的一些取值

沿着环路走，先看环路中有没有矛盾，固定\(K_2\),如果\(K_1\)中一个字母会对应多个字母，那就说明这个\(L_0\)的路径不对

如果\(K_2\)的所有路径都不对，说明这个\(K_2\)是错误的

如果存在没有矛盾的路径，就说明这个\(K_2\)依旧是正确密钥的候选值

\subsubsection{利用Crib恢复\(K_1\)中剩下的取值}

再回到完整的Crib，寻找\(K_1\)中已经有的字母，比如又找到一个W，它又会对应一个新的密文字母比如J

分两种情况
\begin{itemize}
    \item 如果J已经在\(K_1\)中出现过了，那么我们检查\({Enc}_{K_2}(K_1(W)) = K_1(J)\),如果不等，就排除这个\(K_1\),如果所有\(K_1\)都被排除，就排除这个\(K_2\)
    \item 如果J没有出现过，那么就可以继续扩展\(K_1(J) = {Enc}_{K_2}(K_1(W))\)
\end{itemize}
经过这轮筛选之后，我们就能恢复出\(K_1\)和\(K_2\)了

题目中明确了最多六根接线，所以如果我们找到6个接线的情况(就是\(K_1[i]\neq i\)),那其他就没有接线了，直接令\(K_1[i]= i\)

\subsection{代码详解}
\subsubsection{寻找crib}
就是利用前面的不自加密性，两层循环，先把猜测的明文和密文左边对齐，然后外层循环每次将明文往右移动一格，内层循环比对同一个位置的明文和密文
如果相同，那就肯定不是crib
\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{figures/find_crib.png}
\end{figure}
\begin{lstlisting}
def find_crib(c,m):
    cribs = []
    maxl = len(c) - len(m) + 1
    ccount = 0 #密文起始点
    flag = 0
    while(ccount < maxl): #把明文移动，相当于密文的起始点往右移动，明文不动
        temp_c = c[ccount : ccount + len(m)]
        ccount = ccount + 1
        for i in range(len(m)):
            if m[i] == temp_c[i]: # 有重复的, 一定不是crib
                flag = 1
                break
        if flag == 0:
            cribs.append(temp_c)
        else:
            flag = 0
    return cribs  #最后输出是所有可能的crib列表
\end{lstlisting}
但是这一步对本次实验没什么用，因为这次实验给的明密文长度一样，就是一一对应的，这个寻找crib使用的情况就是猜测的明文比密文短
\subsubsection{寻找环路}
找到crib之后，基于前面的思路分析，我们应该寻找crib中的环路部分

从肉眼上看，其实就有点像连线，从明文的一个字符出发，连接他下面的密文，然后要继续连接和密文一样的明文，这有点像二分图那种感觉，因为边只在不同集合之间

等等？二分图，换而言之，对于寻找这样的环路，我们可以把明密文对构建成一个图，基于图的数据结构，是有很多手段可以寻找环的

那这个图是有向图还是无向图呢，一开始认为是有向图，对此我还修改了代码，但是失败了，基于前面说的，我们需要把环路扭一下，因此明密文之间应该是双向的

明文和密文的边同时存在，这样我们就可以找到环路了

这里采用的是邻接表的形式

这里我们既构造明文到密文的边，也构造密文到明文的边，因为Enigma机具有加解密一致性，这样的话，我们可以扭成书上的形式
\begin{lstlisting}
def build_graph(c,m):
    graph = {}
  # 遍历所有的边
    for l,uv  in  enumerate(zip(c,m)):   
        u, v=uv
    # 如果u不在字典中, 就创建一个空列表
        if u not in graph:
            graph[u] = []
    # 把(v, l)这个元组添加到u的邻接列表中, 边权l是边的坐标
        graph[u].append((v, l))
    for l, uv in  enumerate(zip(m,c)):
        u, v=uv  
    # 如果u不在字典中, 就创建一个空列表
        if u not in graph:
            graph[u] = []
    # 把(v, l)这个元组添加到u的邻接列表中, 边权l是边的坐标
        graph[u].append((v, l))
  # 返回字典
    return graph
\end{lstlisting}
接着在图中寻找环
\begin{lstlisting}
def dfs(graph,pos,st,path,locs): # 从左到右依次为构建的无向图, 输入位置字符, 开始位置字符和坐标, 路径, 记录的环路构成边的坐标
    ans=[]
    for i,l in graph[pos]:
        if i in path :
            tmp=(path[path.index(i):]+[i],locs[path.index(i):]+[l])
            if len(set(tmp[1]))>=2 and st[0] not in tmp[0][1:-1] and tmp[1][-1]==st[1]:
                ans+=[(tuple(tmp[0]),tuple(tmp[1]))]
            continue
        ans+=dfs(graph,i,st,path+[i],locs+[l])
    return ans
\end{lstlisting}
我们记录起点，然后从这个点出发，依次遍历他的邻居，再遍历邻居的邻居，只要遍历到的那个点的邻居里面有起点，就结束

我们在dfs的参数中维护了两个列表,path和locs,path记录经过的点,locs记录经过的边

然后来说一下dfs结束的条件，这里的图是多重图，是有可能出现a-b-b-a这种情况的，所以最小的环有两个边

st[0] not in tmp[0][1:-1]是没有必要的，因为st[0]本身就在path里面，而前面我们又对path作了截断，所以这里不需要这个判定条件

tmp[1][-1] == st[1]这个是为了后续调用刻意加的条件
\begin{lstlisting}
graph=build_graph(crib,m)
visited=[0]*len(m)
for i in range(len(m)):
    if visited[i]==1:
        continue    
    ansi=dfs(graph,m[i],(m[i],i),[m[i]],[])
    for find_ins in ansi:
        for loc in find_ins[1]: # 防止重复计算
            visited[loc]=1    
    ans|=set(ansi)        
\end{lstlisting}
这里每找一个环路，就把里面的边都去掉了，这里是有可能漏环的，不过在这次实验里影响不大
\subsubsection{通过环路筛选K2}
\begin{lstlisting}
guess = {}
guess_all_K2 = {(i, j, k) for i in range(26) for j in range(26) for k in range(26)} # 从所有备选中进行筛选
for case in ans:
    guess_case = {} #存放这个case用的K2
    for i in range(26):
        for j in range(26):
            for k in range(26):
                K2 = (i,j,k) #遍历k2
                paths = []
                for check in string.ascii_uppercase:
                    trans = check
                    path = [trans]
                    for z in case[1]:
                        trans = crypt_once(I, II, III, T, (i-z)%26, j, k, trans)
                        path.append(trans)
                    if trans == check:
                        paths.append(path)
                if paths:
                    guess_case[K2] = paths
    guess_all_K2 &= set(guess_case) #把每次case的K2都取交集
    guess[case] = guess_case   #记录路径，guess[case][K2]就能查找这个环的路径
\end{lstlisting}
注意这里的ans是我们前面找到的环路，case就是具体的其中一个环路

这里用guess存储每个环路的\(K_2,L_0\)的候选集

这里我们用i,j,k遍历K2，然后用check遍历26个英文字母,也就是\(L_0\),然后利用crypt\_once依次计算trans，也就是\(L_1,L_2,...\),直到因为环路再算到\(L_0\)

当trans==check的时候,就找到了一个满足环路的K2，然后可能有多个\(L_0\)通过亮灯测试，所以我们用一个paths存储多个path，每通过一个就存入paths

最后我们把K2对应的paths存入guess\_case，guess\_case就是一个环路的候选集，我们最后要取交集，存入guess\_all\_K2，就是满足所有环路的K2

然后这个guess我们可以用case和K2来查找路径
\subsubsection{利用\(K_2\)筛选\(K_1\)}
\begin{lstlisting}
guess_K2_K1 = {}
for K2 in guess_all_K2:
    all_K1 = [{}]   #整体的K1,每个case我们能找到一些K1，相当于先存到这里，然后再下一个case里直接对这个测试
    for case in ans:  #找环路,要在每个环路里面找K1
        possible_K1 = []
        for path in guess[case][K2]:   #找L0,L1,..
            for K1_now in all_K1: #初始就是{}，空集
                flag = True
                K1 = K1_now.copy() #我们后面会改K1，这里得copy一下
                for real,pluged in zip(case[0],path):
                    if real not in K1: #如果K1里没有这个明文，就加进去，然后让他和Li连接
                        K1[real] = pluged
                    elif K1[real] != pluged: #如果有了，但是不是Li，那就矛盾了
                        flag = False
                        break
                    if pluged not in K1:  #反过来对Li也是一样的
                        K1[pluged] = real
                    elif K1[pluged] != real:
                        flag = False
                        break
                if flag:
                    possible_K1.append(K1) #找到符合这个环路的K1
        all_K1 = possible_K1  #把可能的K1放进去
        if len(all_K1) == 0:
            break
    if len(all_K1) > 0:
        guess_K2_K1[K2] = all_K1
\end{lstlisting}
首先依旧是一个字典，guess\_K2\_K1,用来存所有\(K_2\)对应的\(K_1\),先固定\(K_2\),用all\_K1来存放单个\(K_2\)对应的\(K_1\)

然后要在每个环路中寻找\(K_1\),用possible\_K1存放,

一开始all\_K1是空的,我们先在一个环路里得到一批\(K_1\),然后把它放进去，接着第二个环路就可以用这批\(K_1\)挑选

因此每次possible\_K1得到是符合前面所有环路的\(K_1\),因此当遍历完所有环路之后，就令all\_K1=possible\_K1即可
\subsubsection{利用已有的明密文对继续恢复\(K_1\)}
\begin{lstlisting}
final_guess = {}
for K2 in guess_K2_K1: #固定K2
    for K1 in guess_K2_K1[K2]:  #从K2中取出K1
        K1_now = K1.copy()
        ok = True
        flag = True
        while flag and ok: #ok是用来看K1有没有矛盾的，有矛盾直接退出，flag就是看有没有更新状态
            flag = False
            for loc,pair in enumerate(zip(crib,m)):  #明密文对
                known = set(pair) & set(K1_now) #取交集，就是找K1里已经有的字母
                if len(known) != 1: #pair里面就两个字母，如果不等于1，那就是0或者2，就是说都知道或者都不知道，那就不用回复了
                    continue
                known_char = list(known)[0]
                unknown_char = pair[0] if pair[1] == known_char else pair[1] #看明密文里面那个不知道
                plug = crypt_once(I,II,III,T,K2[0]-(loc%26),K2[1],K2[2],K1_now[known_char]) #计算中间状态
                if unknown_char in K1_now:
                    if K1_now[unknown_char] != plug: #这个中间状态和不知道的那个是相连的，如果不想等，就矛盾
                        ok = False
                        break
                elif plug in K1_now:
                    if K1_now[plug] != unknown_char:
                        ok = False
                        break
                else:
                    K1_now[unknown_char] = plug #如果两个在K1里都没有记录，那就直接添加
                    K1_now[plug] = unknown_char
                    flag = True  #因为获取了K1的新信息，所以flag=1，需要重新看一遍
            #如果没有获取新信息，说明没法再更新了，直接退出
        if ok:
            if K2 not in final_guess:
                final_guess[K2] = []
            final_guess[K2].append(K1_now)  #如果没有矛盾就加进去
\end{lstlisting}
因为K2和K1是绑定的，所以每次筛选我们都要一个字典来存放，用final\_guess来存放K2和K1的对应

然后固定K2，从K2中取出K1，因为每次K1得到新消息，就可以再扫描一遍crib获取新的信息

所以我们要用while循环，如果是for循环就不能不断扫描，我们用两个变量，一个flag表示有没有得到新信息，ok表示有没有矛盾

如果得到新信息并且没有矛盾，就重新进入循环，如果有矛盾，那就这个K2就进不了final\_guess
