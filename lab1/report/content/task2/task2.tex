\section{任务二}
给定如下明密文数据流，任务1中的三个转子和反射器的定义不变，但转子顺序不固定，请尝试恢复密钥K1和K2。（假设加密过程中，中速和慢速转子不转动）

明文WETTERVORHERSAGEHEUTE

密文EWGZDSATLWNEDBBCJUNGW

\subsection{思路分析}
明文和密文长度一样，且没有出现明文和密文相同的情况，因此可以认为这就是对应的明密文，即Crib，
由于加密的时候密钥K1和K2是合并起来的，穷举数量太大，因此需要分割密钥空间，我们可以类比2-DES的攻击，
其中的关键就是通过一些相同的中间量来脱去外层加密。

我们注意到这样的一种特殊的Crib，即内部能形成环路的Crib，因为接线板就是一个由连接线决定的单表代换，这个过程和K2没有关系，
enigma机的明文输入会经过一次接线板，而输出密文前也会经过一次接线板，这之间有一个中间状态。

我们就可以利用这个中间状态单独回复\(K_2\)，然后再去恢复\(K_1\)，实现对于密钥空间的分割，降低密钥恢复的复杂度。

以课程上的一个crib为例，
\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{figures/crib.png}
    \caption{Crib}
    \label{fig:Crib}
\end{figure}
明文里的W,经过接线板，\(K_1\)我们可以理解成一个可逆的单表带换，即\(K_1(W)=L_0\)，
然后密文的E，\(K_1(E)=L_1\)，此时我们发现明文的下一个也是E，它得到的中间状态也应该是\(L_1\),那这样我们就能消解掉接线板的影响
(值得注意的是，这里的Crib是一种交替的环路，就是从明文-密文-明文-密文...这样明密文交替进行的，这实际上会影响后续的数据结构，参考程序中并不是这样的，不过这又是后话了)

我们利用这个中间状态来建立K2的方程：

它有一个\textbf{不随机现象}就是，\(L_0\)进\(L_0\)出，
而\(L_1\)本身就是\(L_0\)经过扰频器和反射器得到的，也就是说，知道\(L_0\)和\(K_2\),就能计算\(L_1,L_2\)
\[
L_{i-1} \xrightarrow{K_2} L_i
\]
我们简单把这个步骤记作\({Enc}_{K_2}\)

因此这中间的路径也被消解了，我们只需要关注首尾的\(L_0\),正确的K2应该能让\(L_0\)进\(L_0\)出

我们只需要遍历\(|K_2|\times|L_0|\)次，其中\(|L_0|=26\),这远远小于\(|K_1|\times|K_2|\)的穷举

当然这个也会有错误，但是我们多找几个环路，然后取交集，就能得到比较少的候选了
\subsection{恢复\(K_1\)以及\(K_2\)}
我们前面找到的可能的\(K_2\)的候选集，记为\(\{(L_0^{1i},K_2^1),(L_0^{2i},K_2^2),..., (L_0^{ni},K_2^n)\}\)
因为一个\(K_2\)可能对应多个\(L_0\),所以\(L_0^{1i},K_2^1\)可能有多个\(i\),即多个\(L_0\)对应同一个\(K_2\)

我们可以利用这些候选的\(K_2\)来恢复\(K_1\)，同时进一步筛选\(K_2\)

因为我们已知环路，比如W-E-E-T-T-W

那么就有\(K_1(W)=L_0\)，\(K_1(E)=L_1\)，\(K_1(T)=L_2\)，以此类推

如何筛选呢？就是寻找矛盾，再回到完整的Crib，寻找\(K_1\)中已经有的字母，比如又找到一个W，它又会对应一个新的密文字母比如J

分两种情况
\begin{itemize}
    \item 如果J已经在\(K_1\)中出现过了，那么我们检查\({Enc}_{K_2}(K_1(W)) = K_1(J)\),如果不等，就排除这个候选
    \item 如果J没有出现过，那么就可以继续扩展\(K_1(J) = {Enc}_{K_2}(K_1(W))\)
\end{itemize}

经过这轮筛选之后，我们就能恢复出\(K_1\)和\(K_2\)了

\subsection{步骤}
\subsubsection{寻找crib}
就是利用前面的不自加密性，两层循环，先把猜测的明文和密文左边对齐，然后外层循环每次将明文往右移动一格，内层循环比对同一个位置的明文和密文
如果相同，那就肯定不是crib
\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{figures/find_crib.png}
\end{figure}
\begin{lstlisting}
def find_crib(c,m):
    cribs = []
    maxl = len(c) - len(m) + 1
    ccount = 0 #密文起始点
    flag = 0
    while(ccount < maxl): #把明文移动，相当于密文的起始点往右移动，明文不动
        temp_c = c[ccount : ccount + len(m)]
        ccount = ccount + 1
        for i in range(len(m)):
            if m[i] == temp_c[i]: # 有重复的, 一定不是crib
                flag = 1
                break
        if flag == 0:
            cribs.append(temp_c)
        else:
            flag = 0
    return cribs  #最后输出是所有可能的crib列表
\end{lstlisting}
但是这一步对本次实验没什么用，因为这次实验给的明密文长度一样，就是一一对应的，这个寻找crib使用的情况就是猜测的明文比密文短
\subsubsection{寻找环路}
找到crib之后，基于前面的思路分析，我们应该寻找crib中的环路部分

从肉眼上看，其实就有点像连线，从明文的一个字符出发，连接他下面的密文，然后要继续连接和密文一样的明文，这有点像二分图那种感觉，因为边只在不同集合之间

等等？二分图，换而言之，对于寻找这样的环路，我们可以把明密文对构建成一个图，基于图的数据结构，是有很多手段可以寻找环的

\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{figures/build_graph.png}
\end{figure}
这里采用的是邻接表的形式
\begin{lstlisting}
def build_graph(c,m):  #邻接表
    graph = {}
  # 遍历所有的边
    for l,uv  in  enumerate(zip(c,m)): #enumerate l是索引i,uv就是zip(ci,mi)
        u, v=uv
    # 如果u不在字典中, 就创建一个空列表
        if u not in graph:
            graph[u] = []
    # 把(v, l)这个元组添加到u的邻接列表中, 边权l是边的坐标 坐标就是索引，l=0就是c的第一个字母
        graph[u].append((v, l))
    for l, uv in  enumerate(zip(m,c)):
        u, v=uv  
    # 如果u不在字典中, 就创建一个空列表
        if u not in graph:
            graph[u] = []
    # 把(v, l)这个元组添加到u的邻接列表中, 边权l是边的坐标
        graph[u].append((v, l))
  # 返回字典
    return graph
\end{lstlisting}
在搭建完图之后，我们就可以找环了,我们观察一下，利用数据结构的知识，尝试dfs就行了

值得注意的是，这里的图是多重图，是有可能出现a-b-b-a这种情况的，所以最小的边是2个

我们记录起点，然后从这个点出发，依次遍历他的邻居，再遍历邻居的邻居，只要遍历到的那个点的邻居里面有起点，就结束

我们在dfs的参数中维护了两个列表,path和locs,path记录经过的点,locs记录经过的边

注意dfs算法里的if语句，这里有些冗余,st[0] not in tmp[0][1:-1]是没有必要的，因为st[0]本身就在path里面，而前面我们又对path作了截断

所以这里不需要这个判定条件

注意这里面的代码是相当冗余的，有很大的改进空间，实际上st是没有作用的，因为在使用的时候我们把st已经放进path了

而且写的相当令人费解，一些条件显得非常奇怪
\begin{figure}[H]
    \centering
    \includegraphics[width=0.8\textwidth]{figures/dfs.png}
\end{figure}
\begin{lstlisting}
    def dfs(graph,pos,path,locs): # 从左到右依次为构建的无向图, 输入位置字符, 路径, 记录的环路构成边的坐标
    ans=[]
    for i,l in graph[pos]:
        if i in path : #如果找到了重复的点
            tmp=(path[path.index(i):]+[i],locs[path.index(i):]+[l]) #那就把那个点前面的路径丢掉，只从这个点开始
            if len(set(tmp[1]))>=2: #边大于等于2
                ans+=[(tuple(tmp[0]),tuple(tmp[1]))]
            continue
        ans+=dfs(graph,i,path+[i],locs+[l])
    return ans
\end{lstlisting}
